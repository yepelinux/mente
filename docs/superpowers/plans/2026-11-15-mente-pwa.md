# MENTE PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Installable offline PWA to log the M.E.N.T.E. method (Medir, Exponer, Neutralizar, Transformar, Entrenar) over a 30-day plan, data on-device.

**Architecture:** Static Vite + Preact SPA, no server. Pure domain logic in `src/lib/` (unit-tested), persistence in IndexedDB via `idb-keyval`, JSON export/import for backup. Hash-based routing between 4 screens.

**Tech Stack:** Node 22, Vite, Preact, TypeScript, vite-plugin-pwa, idb-keyval, Vitest + fake-indexeddb + @testing-library/preact (jsdom).

**Spec:** `docs/superpowers/specs/2026-11-15-mente-pwa-design.md`

## Global Constraints

- All UI copy in Spanish (rioplatense "vos"). Code identifiers in English.
- No server, no accounts, no network calls at runtime.
- Only `intensityBefore` (0–10) and `thought` (non-empty after trim) are required to save an entry.
- Plan length: exactly 30 days. Blocks: 1–7 Medir/Exponer, 8–14 Neutralizar, 15–21 Transformar, 22–30 Entrenar.
- Backup reminder when `lastBackupAt` is null or older than 7 days.
- Day-plan prompts are our own text — never book text.
- Mobile-first; dark mode follows `prefers-color-scheme`.
- Vite `base` must be `./` so it works under GitHub Pages subpath.

## Review Focus

1. Day boundaries in local time (entry at 23:59 vs 00:01; UTC-3 user) — day math must use local calendar dates, never UTC ISO slicing. Test in Task 2.
2. Importing a malformed, foreign, or future-`version` backup must be rejected without touching existing data. Test in Task 3.
3. Entries without `intensityAfter` must not break the chart or averages (skipped, not plotted as 0). Test in Task 6.
4. Double-tap on "Guardar" must not create duplicate entries. Test in Task 5.
5. Changing plan start date after logging: existing entries/day checks remain, day number recomputes. Test in Task 2 (`dayOfPlan` pure on date) and Task 6.
